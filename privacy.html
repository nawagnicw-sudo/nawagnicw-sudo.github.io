Kebijakan Privasi – Nota SPM Kramas

Berlaku sejak 17 November 2026.

Nota SPM Kramas adalah aplikasi internal Yayasan Nawagni Cethik Nawasena yang berjalan di komputer staf yayasan. Aplikasi ini tidak tersedia untuk umum dan hanya dipakai dengan akun Google milik yayasan.

Data Google yang diakses

  • Google Drive: mengunggah dan memperbarui file PDF nota penggunaan dana dan dokumen SPM ke folder Drive milik yayasan.
  • Google Sheets: membaca dan menulis spreadsheet realisasi anggaran (RA) milik yayasan.
  • Alamat email akun Google yang dihubungkan, untuk menampilkan akun mana yang tersambung.

Cara data dipakai dan disimpan

  • Data hanya dipakai untuk fungsi di atas, atas perintah staf yayasan.
  • Token akses Google disimpan secara lokal di komputer tempat aplikasi berjalan dan tidak dikirim ke server lain.
  • Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan.
  • Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus akses

Akses dapat dicabut kapan saja melalui menu Google Drive di aplikasi (tombol Putuskan) atau di pengaturan izin Akun Google.
